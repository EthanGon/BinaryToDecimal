# Bin2Dec

A CLI App that lets you convert binary to decimal. 

Example: <br>
"1111" will result in "15". <br>
"-1111" will result in "-15". <br>
"11.01" will result in "3.25". <br>

Program will ask if user want to continue, allow user to input multiple values without having to restart program.

This helped me get a bit more comfortable with C++ syntax.
